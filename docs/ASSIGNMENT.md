# Assignment

Original assignment text as received from the company (Slovenian). This file is the
source of the requirements. Do not edit it; interpretations and design decisions belong
in `CLAUDE.md` and `README.md`.

---

V nadaljevanju bi ti predstavil kratek "Mini AI Support Inbox" iziv, kjer bi radi, da izdelaš preprosto spletno aplikacijo za obdelavo sporočil strank. Zanima nas predvsem kakovost kode, smiselna arhitektura, osnovna varnost, obravnava napak in tvoj način uporabe AI pri razvoju. Dizajn ni prioriteta.

Zahtevane funkcionalnosti:
- Vnos sporočila stranke
- AI klasifikacija sporočila (vprašanje, pritožba, pohvala, drugo)
- Generiranje predloga odgovora z uporabo LLM API-ja
- Shranjevanje sporočil in odgovorov v podatkovno bazo
- Pregled zgodovine sporočil ter možnost urejanja in potrditve odgovora

Tehnične zahteve:
- Frontend: React ali Next.js
- Backend: po lastni izbiri
- Baza: PostgreSQL ali Supabase
- AI: poljuben LLM API
